# jsBasic — JavaScript 기초 복습

「Node.js Design Patterns」 책의 장 구성과는 무관하게, 학습 중 다시 짚고 넘어간
JavaScript 기초 개념들을 모아둔 디렉토리다.

| 디렉토리 | 내용 |
|---|---|
| `class/` | 클래스 문법 기초 |
| `closure/` | 클로저 — 카운터 만들기 등 |
| `function/` | 함수 기초 |
| `promise/` | Promise 기초 — `finally`, `resolve`, `Promise.withResolvers()`, 콜백 에러 처리와의 비교, async/await의 논블로킹 동작 |
